# ResumeForge

ResumeForge is a React + TypeScript resume builder focused on ATS-friendly resumes and PDF export.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Main features

- Multi-step resume editor
- Autosave with localStorage
- Personal information and profile photo
- Experience, education, projects, skills, certifications, languages, and references
- Custom resume sections
- Resume review screen
- Rule-based ATS checks and job-description keyword matching
- ATS Classic, Modern, and Compact templates
- Live template preview
- A4 PDF preview and download
- Responsive editor and mobile Edit/Preview switch
